# 作業依頼
## バグ修正
VP送信時、選択開示項目を送信しない場合のSD-JWTのデータフォーマットが仕様に違反しているようです。
以下を確認して修正してください。

### 仕様
⏺ RFC 9901で明確に規定されています。
  仕様上の正しい形式

  ゼロディスクロージャーの場合: <Issuer-signed JWT>~<KB-JWT> （シングルチルダ）
  RFC 9901には以下のように明記されています：

  "An SD-JWT+KB without Disclosures: <Issuer-signed JWT>~<KB-JWT>"
  形式の比較
  ┌─────────────────────────────────────┬─────────────────────┐                                                                                                                                                                                         
  │               ケース                │     正しい形式      │                                                                                                                                                                                         
  ├─────────────────────────────────────┼─────────────────────┤                                                                                                                                                                                         
  │ ディスクロージャーなし、KB-JWTあり  │ <JWT>~<KB-JWT>      │                                                                                                                                                                                         
  ├─────────────────────────────────────┼─────────────────────┤                                                                                                                                                                                         
  │ 1つのディスクロージャー、KB-JWTあり │ <JWT>~<D1>~<KB-JWT> │                                                                                                                                                                                         
  ├─────────────────────────────────────┼─────────────────────┤                                                                                                                                                                                         
  │ ディスクロージャーなし、KB-JWTなし  │ <JWT>~              │                                                                                                                                                                                         
  └─────────────────────────────────────┴─────────────────────┘                                                                                                                                                                                         
  結論
  <JWT>~~<KB-JWT>（ダブルチルダ）は仕様上正しくありません。
  Walletが送信している<JWT>~~<KB-JWT>形式は、空のディスクロージャーが1つ存在することを意味してしまい、仕様に準拠していません。
  Sources:
  - https://datatracker.ietf.org/doc/rfc9901/
  - https://datatracker.ietf.org/doc/html/draft-ietf-oauth-selective-disclosure-jwt
